详细描述

用于实时预览的渲染器。

PreviewRenderer 在形式上与离线渲染器相似，但并不受 RenderEngine 的管理。

PreviewRenderer::PreviewRenderer ( )

构造渲染器。因为 OpenGL shader 需要在 context 初始化之后再编译， 所以 shader 相关的初始化操作需要单独调用 compile_shaders 方法。

◆ render()

void PreviewRenderer::render ( Scene & scene,
WorkingMode mode,
const DebugOptions & debug_options )

渲染一帧的画面。

该方法会按需更新 GPU 数据、发起所有的 draw call ，但不会交换 back buffer 与 front buffer ，因此不会直接引发画面更新。

参数
scene渲染的场景
mode当前的工作模式，这决定了场景的渲染方式。
debug_options当前的调试选项，这决定了用于调试的特殊图元是否被渲染。
