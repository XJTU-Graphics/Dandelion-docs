详细描述

用于同步渲染数据的三角形 Mesh 。

这个类负责表示可以直接同步到 GPU 的三角形 Mesh 数据。

外界读取 Mesh 中的顶点坐标、法线，以及边和三角形的索引时一般应该使用 positions/normals 等存储向量或定长数组的容器；而渲染器需要向 GPU 同步数据时，则应该直接使用存储 float 或 unsigned int 的扁平 vector 。
